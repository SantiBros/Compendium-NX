**First test version.** It hasn't been tested on a Switch yet, so expect bugs. Please report what happens.

### Which file to download
- **`Compendium.nro`**: this is the app. Copy it to `sd:/switch/Compendium/Compendium.nro` and open it from the Homebrew Menu.
- You don't need "Source code (zip)" or "Source code (tar.gz)": those are only the code, for building it yourself.

### What's in it
- Persona 5 Royal: browse and search GameBanana's Switch and PC mods, and install them on the console.
- Builds the game's `PATCH1.CPK` on the Switch from the mods that are on (or a CPK for the p5rcbt plugin). No PC needed.
- Installs Aemulus packages, ready-made CPKs, Atmosphère and SimpleModManager folders, p5rcbt folders and loose game files, and adapts PC (Reloaded-II) mods.
- Load order, conflict warnings, turning mods on and off without deleting them.
- Add mods from the SD card inbox, SimpleModManager's `mods` folder, a `PATCH1.CPK` copied by hand, GitHub, a GameBanana mod number or a link from your phone.

### If something goes wrong
Send `switch/Compendium/log.txt` (and, if the app crashed, the newest file in `atmosphere/crash_reports`). Hold **L** while starting the game to play once without mods.
