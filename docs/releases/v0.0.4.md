**More mods end up where the game looks for them.** Compendium is a mod manager for Persona games on Nintendo Switch: it installs mods for Persona 5 Royal from GameBanana and builds the game's `PATCH1.CPK` on the console, no PC needed. For this version, every Persona 5 Royal mod for Switch on GameBanana went through the app's rules, to find the ones that would go to the wrong place like the opening mod did. Still a test version: back up your saves, and please report what happens.

> [!IMPORTANT]
> No game files are included. You need your own copy of Persona 5 Royal for Switch, and a console with Atmosphère.

### Which file do I download?

| File | What it is |
|---|---|
| **`Compendium-0.0.4.zip`** | **The app. This is the only file you need.** |
| Source code (zip / tar.gz) | Added by GitHub: only the code, for building it yourself. Nothing to run. |

### How to install or update
1. Unzip `Compendium-0.0.4.zip` and copy its **`switch`** folder to the root of your SD card. It joins the `switch` folder already there (and replaces the old version), and the app ends up in `switch/Compendium/`. Your mods and settings are kept. (On a Mac, Finder replaces folders instead of joining them: copy just the `Compendium` folder into your SD card's `switch` folder.)
2. Hold **R** while starting any game to open the Homebrew Menu, and choose **Compendium**.
3. If an earlier version put some of your mods' files in the wrong folder, 0.0.4 fixes them and builds the game's mod files again the first time it opens. Wait until it's done, then press **+** and start Persona 5 Royal.

Recommended once, if you haven't yet: close the app, hold **L and R** while starting Persona 5 Royal until the Homebrew Menu opens, and open Compendium. It reads the game's own file list, which it uses to put more mods' files in the right place. The full guide: [docs/INSTALL.md](https://github.com/SantiBros/Compendium-NX/blob/main/docs/INSTALL.md).

### What's new
- **Fixed: some Aemulus packages' files went to the wrong folder.** Folders named after the PC version's CPKs (`BASE.CPK`, `EN.CPK`), like in "Persona 25th Anniversary Decals", and the English voices folder `SOUND_E`, like in "Gay Joker", ended up inside `BASE/`, where the game never looks.
- **Fixed: files in the game's `BUSTUP`, `CUTIN`, `BUTTON`… folders were left out** when they came without `BASE/` or `EN/`, like in "Yoshizawa Hair Down". Install those mods again.
- **Exefs patches** (`.ips` files named by the game's build id, like "Max Handheld Resolution") are installed in Atmosphère's `exefs_patches` folder.
- **Files that come without any folder** (like a music pack with just `BGM.ACB` and `BGM.AWB`) go where the game has a file with the same name. This uses the game's own file list (the L + R step above).
- **Save files are recognized**: instead of being installed as a mod, the app tells you to copy them with a save manager such as JKSV. **Emulator-only mods** (`.pchtxt`) get a clear message too.
- From 0.0.3: mods made to be packed on a PC with CriWare's `cpkmakec`, like the one that brings back Persona 5's opening, work.

**Not yet:** changes that Aemulus merges on a PC. In about ten mods (new names, stats or item descriptions: table patches and text that goes inside the game's own archives), the models and textures install, but those changes don't show yet.

All the details are in the [changelog](https://github.com/SantiBros/Compendium-NX/blob/main/CHANGELOG.md).

### Cómo instalar o actualizar
1. Descomprime `Compendium-0.0.4.zip` y copia su carpeta **`switch`** en la raíz de tu tarjeta SD. Se une a la carpeta `switch` que ya está (y reemplaza la versión anterior), y la app queda en `switch/Compendium/`. Tus mods y ajustes se conservan. (En un Mac, Finder reemplaza las carpetas en vez de unirlas: copia solo la carpeta `Compendium` dentro de la carpeta `switch` de tu SD.)
2. Mantén **R** al abrir cualquier juego para que aparezca el Homebrew Menu, y elige **Compendium**.
3. Si una versión anterior puso archivos de tus mods en una carpeta equivocada, la 0.0.4 los corrige y vuelve a armar los archivos de mods del juego la primera vez que la abres. Espera a que termine, pulsa **+** y abre Persona 5 Royal.

Recomendado una vez, si todavía no lo hiciste: cierra la app, mantén **L y R** al abrir Persona 5 Royal hasta que aparezca el Homebrew Menu, y abre Compendium. Lee la lista de archivos del propio juego, que usa para poner los archivos de más mods en su lugar. ### Qué hay de nuevo
- **Arreglado: los archivos de algunos paquetes de Aemulus iban a la carpeta equivocada.** Las carpetas con el nombre de los CPK de la versión de PC (`BASE.CPK`, `EN.CPK`), como en "Persona 25th Anniversary Decals", y la carpeta de las voces en inglés `SOUND_E`, como en "Gay Joker", terminaban dentro de `BASE/`, donde el juego nunca busca.
- **Arreglado: los archivos de las carpetas `BUSTUP`, `CUTIN`, `BUTTON`… del juego se quedaban fuera** cuando venían sin `BASE/` o `EN/`, como en "Yoshizawa Hair Down". Vuelve a instalar esos mods.
- **Los parches de exefs** (archivos `.ips` con el build id del juego como nombre, como "Max Handheld Resolution") se instalan en la carpeta `exefs_patches` de Atmosphère.
- **Los archivos que vienen sin ninguna carpeta** (como un pack de música con solo `BGM.ACB` y `BGM.AWB`) van donde el juego tiene un archivo con el mismo nombre. Para esto usa la lista de archivos del propio juego (el paso de L + R de arriba).
- **Las partidas guardadas se reconocen**: en lugar de instalarse como un mod, la app te dice que las copies con un gestor de partidas como JKSV. **Los mods solo para emuladores** (`.pchtxt`) también tienen un mensaje claro.
- De la 0.0.3: funcionan los mods hechos para armarse en un PC con `cpkmakec` de CriWare, como el que trae la intro de Persona 5.

**Todavía no:** los cambios que Aemulus combina en un PC. En unos diez mods (nombres, estadísticas o descripciones de objetos nuevos: parches de tablas y textos que van dentro de los archivos propios del juego), los modelos y texturas se instalan, pero esos cambios todavía no aparecen.

Todos los detalles están en el [registro de cambios](https://github.com/SantiBros/Compendium-NX/blob/main/CHANGELOG.md) (en inglés).
